# Autonomous AI Startup Consultant Platform

A production-grade, multi-agent strategic business consulting and validation engine. Users submit a startup idea, and a coordinated pipeline of **7 specialized AI agents** conducts real-time web research, competitive mapping, financial projection calculations, SWOT matrix styling, pitch deck structuring, and compiles the result into an investor-ready PDF document.

---

## ⚡ Key Platform Features
- **Sequential Multi-Agent Orchestration**: Sequential execution pipeline managed asynchronously using **Celery** + **Redis**.
- **Real-Time Market Validation**: Live data scraping and information gathering via **Tavily API**.
- **Structured LLM Planning**: Complete business plan structures generated by **Groq** (`llama3-70b-8192`) via **LangChain**.
- **Contextual User Memory**: Automatically injects previous report findings into agent prompts using **ChromaDB** vector databases.
- **RAG Q&A (Document Q&A)**: Upload business PDF or DOCX documents to query and extract insights with ChromaDB similarity scoring.
- **Hosted Outputs**: Automated professional PDF compilation with **ReportLab** and remote storage upload via **Cloudinary**.
- **Premium Glassmorphism UX**: Dark neon design built using **Next.js 14**, **Tailwind CSS**, and interactive data displays with **Recharts**.

## 🛠️ Local Backend Development Setup

### 1. Configure Backend Variables
Create a file named `.env` in the root of the project:
```bash
GROQ_API_KEY="your_groq_api_key_here"
GROQ_MODEL="llama3-70b-8192"
TAVILY_API_KEY="your_tavily_api_key_here"
DATABASE_URL="postgresql+asyncpg://postgres:postgres@localhost:5432/startup_consultant"
CHROMA_PERSIST_DIR="./vector_db/chroma_data"
JWT_SECRET_KEY="generate_a_secure_jwt_random_key"
JWT_ALGORITHM="HS256"
ACCESS_TOKEN_EXPIRE_MINUTES=1440
REDIS_URL="redis://localhost:6379/0"
CLOUDINARY_CLOUD_NAME="your_cloudinary_cloud_name"
CLOUDINARY_API_KEY="your_cloudinary_api_key"
CLOUDINARY_API_SECRET="your_cloudinary_api_secret"
ENVIRONMENT="development"
FRONTEND_URL="http://localhost:3000"
REPORTS_DIR="./reports"
```

### 2. Startup Infrastructure
Ensure **Docker Desktop** is running, then stand up Redis, PostgreSQL, and ChromaDB:
```bash
docker-compose up -d
```

### 3. Install Python Dependencies
Set up a python virtual environment (Python 3.11 recommended):
```bash
python -m venv venv
venv\Scripts\activate      # On Windows
source venv/bin/activate    # On macOS/Linux
pip install -r requirements.txt
```

### 4. Run Alembic Database Migrations
Create and run the tables configuration layout:
```bash
alembic upgrade head
```

### 5. Launch Services
Open two terminal windows (with virtual environment active in both):

**Terminal 1: Start FastAPI Web Server**
```bash
uvicorn backend.main:app --reload --port 8000
```
- Interactive API Documentation: [http://localhost:8000/docs](http://localhost:8000/docs)

**Terminal 2: Start Celery Worker Queue**
```bash
celery -A backend.celery_app.celery_app worker --loglevel=info --concurrency=2
```

## 🎨 Local Frontend Development Setup

### 1. Configure Environment Variables
Create a file named `frontend/.env.local`:
```bash
NEXT_PUBLIC_API_URL=http://localhost:8000/api/v1
```

### 2. Install Node.js Dependencies
Navigate to the frontend folder and install standard modules:
```bash
cd frontend
npm install
```

### 3. Run Development Server
Start the Hot-Reload dev environment:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
